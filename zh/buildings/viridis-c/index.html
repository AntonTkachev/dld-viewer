常见问题

VIRIDIS C 每平方英尺多少钱？

近 12 个月，VIRIDIS C 的中位价为每平方英尺 AED 937（每平方米 AED 10,085），基于 25 笔 DLD 登记成交。

VIRIDIS C 的租金是多少？

2026 年年租金中位数为 AED 43,101，基于 245 份 Ejari 合同（整个项目）。

VIRIDIS C 的租金收益率是多少？

毛收益率约 8.2%：近 24 个月每平方米年租金 AED 832，对应每平方米价格 AED 10,168。
