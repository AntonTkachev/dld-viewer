关于 OLIVZ RESIDENCE BLOCK 3 的常见问题

OLIVZ RESIDENCE BLOCK 3 每平方英尺多少钱？

近 12 个月，OLIVZ RESIDENCE BLOCK 3 的中位价为每平方英尺 AED 1,189（每平方米 AED 12,799），基于 13 笔 DLD 登记成交。

OLIVZ RESIDENCE BLOCK 3 的租金是多少？

2026 年年租金中位数为 AED 49,309，基于 178 份 Ejari 合同（整个项目）。

OLIVZ RESIDENCE BLOCK 3 的租金收益率是多少？

毛收益率约 8.4%：近 24 个月每平方米年租金 AED 1,034，对应每平方米价格 AED 12,362。
