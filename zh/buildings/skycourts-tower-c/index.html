关于 Skycourts Tower C 的常见问题

Skycourts Tower C 每平方英尺多少钱？

近 12 个月，Skycourts Tower C 的中位价为每平方英尺 AED 712（每平方米 AED 7,663），基于 53 笔 DLD 登记成交。

Skycourts Tower C 的租金是多少？

2026 年年租金中位数为 AED 52,370，基于 1,195 份 Ejari 合同（整个项目）。

Skycourts Tower C 的租金收益率是多少？

毛收益率约 8.7%：近 24 个月每平方米年租金 AED 665，对应每平方米价格 AED 7,596。
