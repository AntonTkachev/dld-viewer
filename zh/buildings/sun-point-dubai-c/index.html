关于 Sun Point Dubai C 的常见问题

Sun Point Dubai C 每平方英尺多少钱？

近 12 个月，Sun Point Dubai C 的中位价为每平方英尺 AED 1,263（每平方米 AED 13,598），基于 4 笔 DLD 登记成交。

Sun Point Dubai C 的租金是多少？

2026 年年租金中位数为 AED 61,151，基于 70 份 Ejari 合同（整个项目）。

Sun Point Dubai C 的租金收益率是多少？

毛收益率约 7.1%：近 24 个月每平方米年租金 AED 959，对应每平方米价格 AED 13,489。
