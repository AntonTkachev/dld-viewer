关于 SILICON GATE 3 的常见问题

SILICON GATE 3 每平方英尺多少钱？

近 12 个月，SILICON GATE 3 的中位价为每平方英尺 AED 857（每平方米 AED 9,224），基于 8 笔 DLD 登记成交。

SILICON GATE 3 的租金是多少？

2026 年年租金中位数为 AED 55,652，基于 56 份 Ejari 合同。

SILICON GATE 3 的租金收益率是多少？

毛收益率约 8.6%：近 24 个月每平方米年租金 AED 719，对应每平方米价格 AED 8,327。
