关于 Park Point Building C 的常见问题

Park Point Building C 每平方英尺多少钱？

近 12 个月，Park Point Building C 的中位价为每平方英尺 AED 2,165（每平方米 AED 23,308），基于 6 笔 DLD 登记成交。

Park Point Building C 的租金是多少？

2026 年年租金中位数为 AED 132,089，基于 146 份 Ejari 合同（整个项目）。

Park Point Building C 的租金收益率是多少？

毛收益率约 6.3%：近 24 个月每平方米年租金 AED 1,437，对应每平方米价格 AED 22,686。
