关于 CLOUD B 的常见问题

CLOUD B 每平方英尺多少钱？

近 12 个月，CLOUD B 的中位价为每平方英尺 AED 1,423（每平方米 AED 15,312），基于 32 笔 DLD 登记成交。

CLOUD B 的租金是多少？

2026 年年租金中位数为 AED 72,631，基于 236 份 Ejari 合同（整个项目）。

CLOUD B 的租金收益率是多少？

毛收益率约 8.3%：近 24 个月每平方米年租金 AED 1,280，对应每平方米价格 AED 15,472。
