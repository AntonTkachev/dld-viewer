Sun Point Dubai C में प्रति वर्ग फुट कीमत क्या है?

पिछले 12 महीनों में Sun Point Dubai C की माध्य कीमत AED 1,263 प्रति वर्ग फुट (AED 13,598/m²) रही, 4 DLD-पंजीकृत बिक्री के आधार पर।

Sun Point Dubai C में किराया कितना है?

Sun Point Dubai C की रेंटल यील्ड क्या है?
